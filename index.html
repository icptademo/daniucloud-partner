渠道合作笔记

把开户和充值做成一条渠道

写给准备代理阿里云国际、腾讯云国际、AWS、Google Cloud 或 Azure 开户与充值的人。你负责获客和需求，返佣、白标、下级代理和结算口径在签约前写清楚。控制台操作步骤不在这里展开。

适合谁

有企业客户、区域渠道或云服务客户资源的个人和服务商。没有技术团队也可以提交意向，但要说清客户从哪来。

四种模式

代理合作、渠道分销、技术联运、方案共建。按你现在的接单方式选，不按听起来最大的名字选。

比例不写在这里

阶梯返佣按月结算。计算口径、周期、退款扣减和对账方式，以沟通后的书面条件为准。
